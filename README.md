# Консольное приложение APP

Консольное приложение для управления параметрами подключения и передачи данных.

## Краткое описание

Приложение предоставляет консольный интерфейс с интерактивным текстовым меню для настройки и мониторинга параметров соединения. Конфигурация приложения может быть загружена из JSON-файла либо задана вручную через аргументы командной строки и меню. Меню дополнительно содержит строку статуса, что позволяет контролировать текущее состояние системы.

## Основные возможности

- **Интерактивное текстовое меню** с строкой статуса и описанием доступных команд
- **Загрузка конфигурации** из JSON-файла через параметр командной строки --config
- **Регистронезависимые команды** (например `ACTIVE`, `active` и `Active` работают одинаково)
- **Обработка непечатных символов** при вводе
- **Цветная индикация** состояния (активный или неактивный режим выделяется цветом)
- **Позиционные аргументы** - все параметры команд вводятся непосредственно после имени команды
- **Валидация вводимых данных** с сообщениями об ошибках

## Процесс сборки

### Требования
- CMake 3.14+
- C++17 совместимый компилятор (протестировано с GCC 12)
- Linux (протестировано в Ubuntu 24.04)

> **Примечание:** для проверки IP-адресов используется POSIX-функция `inet_pton`, поэтому приложение работает только на Posix-совместимых системах. Поддержка Windows не предусмотрена.

### Сборка

```bash
# клонирование репозитория
git clone https://github.com/folp3x/protei.git
cd protei

# создание директории для сборки
mkdir build && cd build

# генерация файлов сборки и компиляция
cmake -S . -B build
cmake --build build --target app

# при необходимости указать путь к компилятору
cmake -S . -B build -DCMAKE_C_COMPILER=/usr/bin/gcc-12 -DCMAKE_CXX_COMPILER=/usr/bin/g++-12

# запуск c примером конфигурации
cd build
./app --config ./data/config.json
```

## Примеры использования

### Строка статуса

При запуске отображается шапка с актуальной информацией:

- **IMSI** — идентификатор абонента
- **State** — текущее состояние (active или inactive)
- **Location** — вектор позиции в формате (X, Y, Z)
- **Protocol** — текущий протокол передачи данных (binary или json)

### Доступные команды

`exit`

Завершает работу.

```bash
> exit
Exiting app...
```

`active`

Меняет состояние по булеву значению.

```bash
> active true
Status changed to active

> active false
Status changed to inactive

> active 1
Status changed to active

> active 0
Status changed to inactive
```

`move`

Меняет значение вектора позиции. В зависимости от количества переданных аргументов меняются определенные составляющие вектора.

```bash
> move 1.1
Position changed to (1.1, 0, 0)

> move 1.1 2
Position changed to (1.1, 2, 0)

> move 1.1 2 3
Position changed to (1.1, 2, 3)
```

`protocol`

Задает способ представления данных при передаче.

```bash
# выбор бинарного формата
> protocol binary
Protocol changed to binary

# выбор JSON-формата
> protocol json
Protocol changed to json
```
### Аргументы командной строки

Приложение поддерживает как загрузку конфигурации из файла, так и прямое указание параметров. При этом должен быть указан либо --config (без других флагов) либо любой другой флаг.

```bash
# загрузка полной конфигурации из JSON
./app --config path_to_json

# указание параметров по отдельности
./app --ip 127.0.0.1 --port 8080 --imei 123456789012345 --imsi 543210987654321 --loc 1.1 2 3
```

Доступны следующий опции:

| Опция | Тип данных | Описание |
|-------|-----|----------|
| `-a, --ip` | IPv4 | IP-адрес |
| `-p, --port` | integer | Номер порта |
| `-e, --imei` | char[15] | Идентификатор устройства |
| `-i, --imsi` | char[15] | Идентификатор абонента |
| `-l, --loc` | real[3] | Вектор позиции (X Y Z) |
| `-k, --config` | string | Путь к JSON-файлу конфигурации |
| `-n, --nodes` | string | Путь к JSON-файлу nodes |

> **Примечание**: для опции --nodes реализована только проверка наличия файла .json. Считывание данных из файла не реализовано.

### Пример конфигурационного файла

```json
{
    "ip": "127.0.0.1",
    "port": 8080,
    "imei": "123456789012345",
    "imsi": "543210987654321",
    "loc": [7, 6, 2],
    "protocol": "binary"
}
```

> **Примечание**: все поля являются обязательными.
